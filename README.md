# かんたん請求書メーカー v0.2

ブラウザ上で簡単に請求書を作成できるWEBアプリです。

基本的には、HTMLファイルをローカルにダウンロードして使用することを想定しています。

> **重要**
> 本ツールは汎用的な請求書発行システムではなく、個人・小規模用途を想定した簡易的なWEBアプリです。
> 実際の業務で使用する場合は、必要に応じて内容やレイアウトをカスタマイズしてください。


## 使い方

1. 本リポジトリ内の`seikyusho-maker.html`をダウンロードします。
2. ダウンロードしたHTMLファイルをダブルクリックしてブラウザで開きます。
3. 宛名・日付・金額を入力し、`請求書をリストに追加`ボタンを押します。
4. 入力した内容をもとに請求書が作成され、画面下部の印刷エリアに表示されます。
5. 請求書を複数作成した場合は、画面上の一覧から個別に削除することもできます。
6. `印刷する`ボタンを押すと、ブラウザの印刷プレビューが表示されます。
7. プリンターを選択して印刷してください。

請求書1つのサイズは、**横21cm × 縦8cm**です。

1枚のA4用紙につき最大3枚の請求書を印刷できます。

> **Ver 0.1の印刷仕様**
>
> - 用紙サイズ：A4
> - 請求書1枚：横21cm × 縦8cm
> - A4用紙1枚につき最大3枚
> - A4以外の用紙サイズは想定していません
> - 印刷結果は使用するブラウザやプリンターの設定によって異なる場合があります

※ダウンロードする前に、[サンプルページ](https://koutarou4096.github.io/seikyusho-maker/seikyusho-maker.html)で、使い勝手や機能などを確認することをおすすめします。


## カスタマイズ方法

初期状態では、挨拶文や振込先口座がサンプル用の内容になっています。

実際に使用する場合は、これらを自分の用途に合わせて変更してください。


### 1. HTMLファイルをテキストエディタで開く

ダウンロードしたHTMLファイルを右クリックし、`プログラムから開く`から、お使いのテキストエディタを選択します。

Visual Studio Code、サクラエディタなどを使用できます。

Windowsの場合は、メモ帳でも編集できます。


### 2. 挨拶文を変更する

`Ctrl` + `F`で検索窓を開き、

```text
const THANK_YOU_MESSAGE
````

を検索してください。

以下のような部分が見つかります。

```javascript
const THANK_YOU_MESSAGE =
  "この度はご注文いただきありがとうございます。お手数をおかけしますが、" +
  "お手元に届きましたら、記載されている金額をお早めに下記の口座にお振込みください。";
```

`"`で囲まれている文章を、自分の用途に合わせて書き換えてください。

例えば、

```javascript
const THANK_YOU_MESSAGE =
  "この度はご利用いただきありがとうございます。";
```

のように変更できます。

### 3. 振込先を変更する

同様に、

```text
const BANK_INFO
```

を検索してください。

以下のような部分が見つかります。

```javascript
const BANK_INFO =
  "○○銀行 ○○支店（店番:000） 普通 1234567 名義:ヤマダ タロウ";
```

`"`で囲まれている部分を、実際の振込先情報に書き換えてください。

例：

```javascript
const BANK_INFO =
  "○○銀行 ○○支店（店番:123） 普通 1234567 名義:ヤマダ タロウ";
```

### 4. 保存して確認する

編集が終わったらHTMLファイルを上書き保存してください。

その後、ブラウザでHTMLファイルを開き直し、実際に請求書を作成して、変更内容が正しく反映されているか確認してください。

> **注意**
>
> HTMLファイルを直接編集するため、JavaScriptの構文を誤って変更するとアプリが正常に動作しなくなる可能性があります。
>
> 変更する際は、必要な文字列だけを書き換えることをおすすめします。

## データの保存について

本ツールにはデータを保存する機能はありません。

入力した請求書データは、ページを開いている間だけブラウザ上のJavaScriptによって一時的に保持されます。

そのため、

* ページを再読み込みする
* ブラウザのタブを閉じる
* ブラウザを終了する

などの操作を行うと、作成した請求書データは失われます。

必要な請求書は、データを失う前に印刷してください。

また、本ツールにはサーバーやデータベースなどのバックエンドは存在しません。

## セキュリティについて

Ver. 0.2では、宛名などの入力値は、請求書を生成する際にHTMLエスケープ処理を行っています。

そのため、`<`や`>`などの特殊文字を含む文字列を入力しても、それらがHTMLタグとして実行されないようになっています。

ただし、本ツールはあくまでローカルで使用することを想定した簡易的なアプリです。

信頼できないHTMLファイルを実行したり、改変されたHTMLファイルを使用したりする場合は注意してください。

## 対応環境・画面表示について

本ツールはPCでの使用を前提として制作しています。

画面表示についてはレスポンシブデザインを採用していないため、スマートフォンや一部のタブレット端末ではレイアウトが崩れる可能性があります。

また、印刷機能についてもPCのブラウザでの使用を前提としています。

## 制作環境・検証環境

* Visual Studio Code
* Google Chrome 152.0.7977.83

※ブラウザやプリンターの環境によって、画面表示・印刷結果が異なる場合があります。
