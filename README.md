# かんたん請求書メーカー v0.1
ブラウザ上で簡単に請求書が作れるツール

## 使い方
1. 本リポジトリ内の"seikyusho-maker.html"をダウンロードしてください。
2. ダウンロードしたHTMLファイルをダブルクリックで開きます。
3. 宛名・日付・金額を入力し、「リストに追加」ボタンを押すと請求書が作成されます。
4. 「印刷する」を押すと印刷プレビューが出てきて、プリンターと接続すれば、印刷が可能となります。
   サイズは、横21cmの縦8cmである。1枚のA4用紙につき最大3つ作成できる。（Ver 0.1では、A4以外の紙に印刷することは想定していません。）

## カスタマイズ方法
そのままでは、挨拶文や振込先口座の部分がよく分からないものとなっているので、この部分をカスタマイズする必要があります。
> ※ここでは、HTMLファイルの編集もできるテキストエディタ（Visual Studio Code、サクラエディタなど）がすでにお使いのPCにインストールされている前提で、手順を説明します。（Windowsならメモ帳でも可能です。めちゃくちゃしんどいけどね。）
1. ダウンロードしたHTMLファイルを右クリックし、"プログラムから開く"から、お使いのテキストエディタまたはメモ帳を選択します。
2. Ctrl + Fして、検索窓に"const THANK_YOU_MESSAGE"と入力します。
3. ジャンプした先のプログラムのとこにある定数（メッセージの部分）を書き換えてください。
4. 書き換えが終わったら上書き保存し、一度ブラウザで開いて適当に入力して請求書を作成してみて、正しく反映されているか確認してください。
同様の手順で、"const BANK_INFO"も書き換えてください。

## 注意点
- 入力したデータは、端末内には保存されません。ページを閉じた瞬間消えますので、注意してください。
- entry.nameなどがエスケープ処理なしでテンプレートに埋め込まれているため、名前の欄に特殊文字（`<`や`>`など）を含む文字列を入れるとレイアウトが崩壊する可能性があるので、特殊文字の入力は避けたほうが良いと思います。
